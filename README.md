# Ember & Olive Restaurant

A complete responsive restaurant website built with Next.js 16.

## Included

- Home, menu, dish details, story, reservations, and contact pages
- Interactive table and private-room availability
- Mobile navigation that closes outside the menu, on link selection, or with Escape
- High-quality WebP imagery only (no PNG or JPG assets)

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal.
